🏆 拿分要点

蛋白质变性 vs 盐析：变性破坏空间结构多不可逆，盐析可逆，两者都不破坏肽键。

分子量计算：n 个氨基酸 → (n-1) 个肽键、脱去 (n-1) 个 H₂O。

双链 DNA 中 A=T、G≡C、(A+G)/(T+C)=1。

⚠️ 三个“最多”易混淆

鲜重元素最 O、化合物最水、干重最蛋白质。

无机盐以离子形式存在，不是化合物形式。

考点1.2 细胞的基本结构 · 膜系统与细胞器分工

模块一 细胞的结构基础

📊 结构功能一览

结构核心拿分点高频易混/高阶
细胞膜流动镶嵌模型：磷脂双层（骨架）+蛋白质（功能）；选择透过性膜蛋白分类：受体（糖蛋白）、转运（通道/载体）、酶、识别
能量转化器线粒体（有氧呼吸）、叶绿体（光合）— 半自主性（自有DNA/核糖体）内共生说证据：双层膜、环状DNA、70S核糖体、分裂增殖
蛋白加工链核糖体（合成）→ER（加工）→高尔基体（分选/分泌）→分泌泡分选信号：信号肽（入ER）、甘露糖-6-磷酸（入溶酶体）、NLS（入核）
稳态类溶酶体（降解）、液泡（贮存/渗透）、过氧化物酶体（过氧化氢酶）差速离心顺序：核→线粒体/叶绿体→微粒体→核糖体
细胞核核膜（双层+核孔）、染色质（DNA+蛋白）、核仁（rRNA合成）核孔：小分子被动、大分子主动（NLS+受体+ATP）；成熟RBC无核
生物膜系统核膜-ER-高尔基-溶酶体-质膜；结构相似/功能特异/相互转化原核无生物膜系统；病毒无细胞结构

🏆 分泌蛋白合成运输全链路

核（转录）→ 核糖体（翻译）→ 粗面内质网（加工/折叠）→ 囊泡 → 高尔基体（分类/包装）→ 囊泡 → 细胞膜（胞吐）→ 细胞外。

膜面积变化：内质网 ↓、高尔基体 ≈、细胞膜 ↑。

放射性同位素标记氨基酸：核糖体→内质网→高尔基体→细胞膜。

🎯 难点突破

半自主性细胞器：线粒体/叶绿体含 DNA/RNA/核糖体，但绝大多数蛋白由核基因编码。

生物膜系统：结构相似、功能协同；原核细胞和病毒无此系统。

📌 渗透作用核心模型

水势 Ψ = Ψs（溶质势）+ Ψp（压力势）；水由 高水势 → 低水势。

植物细胞：质壁分离（高渗失水/原生层离壁）vs 复原（低渗吸水）。

装置液面分析：U 型管/渗透仪 — 液面升降 ⇔ 水净流动方向 ⇔ 浓度变化。

考点2.2 酶与ATP · 代谢调控核心枢纽

模块二 细胞代谢

📌 核心知识 · 酶

本质：绝大多数蛋白质、少数 RNA（核酶）；降低活化能（ΔG≠不变）。

特性：高效（10⁷~10¹³ 倍）、专一性（一酶一底物/一反应）、温和条件（37℃、pH7.4）。

影响因素曲线：温度/pH 钟形（变性不可逆 vs 适宜可逆）；底物浓度双曲线→Vmax/Km；酶浓度直线过原点。

抑制/激活：竞争性（结构类似/Km↑ Vmax不变）vs 非竞争性（变构位点/Km不变 Vmax↓）；别构调节/反馈抑制。

📌 核心知识 · ATP

结构：A（腺嘌呤）+R（核糖）+3P；高能磷酸键（~30.5 kJ/mol）。

循环：ATP ⇌ ADP + Pi + 能量（偶联吸能/放能反应）；非能源/非催化/非遗传。

合成途径：光合光反应（叶绿体）、细胞呼吸（线粒体/细胞质）、底物水平磷酸化。

📊 辅酶体系

辅酶全称传递主要分布关键作用
NAD⁺/NADH烟酰胺腺嘌呤二核苷酸[H]（2e⁻+H⁺）细胞质/线粒体糖酵解/三羧酸/呼吸链传氢
NADP⁺/NADPH磷酸化 NAD⁺[H]叶绿体/细胞质光合暗反应/脂肪酸合成/解毒
FAD/FADH₂黄素腺嘌呤二核苷酸[2H]线粒体三羧酸/β-氧化/呼吸链复合体II
CoA辅酶A乙酰基（~S-CoA）线粒体/细胞质乙酰CoA枢纽/脂肪酸代谢

考点2.3 细胞呼吸 · 物质能量精细账本

模块二 细胞代谢

📊 有氧呼吸四大阶段

阶段场所物质变化能量产出关键拿分点
糖酵解细胞质基质葡萄糖→2丙酮酸+4[H]+2ATP净得2ATP、2NADH不需O₂、共同途径、PFK限速
丙酮酸氧化脱羧线粒体基质2丙酮酸→2乙酰CoA+2CO₂+4[H]2NADH连接反应、产生CO₂
三羧酸循环线粒体基质2乙酰CoA→4CO₂+6NADH+2FADH₂+2ATP6NADH、2FADH₂、2ATP草酰乙酸再生、CO₂全部产生于此
电子传递/氧化磷酸化线粒体内膜10NADH+2FADH₂+6O₂→10H₂O+~28-30ATP~28-30ATP质子梯度驱动ATP合酶、化学渗透、抑制剂

🏆 无氧呼吸与呼吸商

无氧呼吸（动物）：丙酮酸→乳酸（还原 NADH→NAD⁺）；仅 2ATP、乳酸堆积→疲劳。

无氧呼吸（酵母/高等植物）：丙酮酸→乙醛→乙醇+CO₂；仅 2ATP、工业发酵应用。

呼吸商 RQ = CO₂产生量 / O₂消耗量：糖类=1.0；脂肪≈0.7；蛋白质≈0.8-0.9。

总账：C₆H₁₂O₆+6H₂O→6CO₂+20[H]+4ATP（底物水平）+ 10O₂→10H₂O+~28-30ATP（氧化磷酸化）≈ 30-32 ATP/葡萄糖。

⚠️ 阶段易错陷阱

有氧呼吸产生水在 第三阶段，不是第一阶段。

CO₂ 产生在 第二阶段，不是第三阶段。

线粒体不能直接利用葡萄糖 — 进入线粒体的是丙酮酸。

植物无氧呼吸不一定都产生酒精 — 玉米胚、马铃薯块茎产生乳酸。

考点2.4 光合作用 · 双相应答与碳同化

模块二 细胞代谢

📌 光反应（类囊体膜）

色素系统：叶绿素a/b（蓝紫/红光）、类胡萝卜素（蓝紫/保护）；光系统II（P680）→光系统I（P700）。

电子传递链：H₂O→PSII→PQ→Cyt b₆/f→PC→PSI→Fd→NADP⁺。

产出：O₂（水光解）、ATP（光合磷酸化）、NADPH。

循环/非循环光磷酸化：仅PSI循环→仅ATP、不产O₂/NADPH；调节ATP/NADPH比例。

📌 暗反应 / 卡尔文循环（叶绿体基质）

3CO₂ + 9ATP + 6NADPH + 5H₂O → 3-PGA → G3P；6轮合成 1 个葡萄糖（18ATP + 12NADPH）。

关键酶：RuBPCase（羧化/加氧竞争→光呼吸）、磷酸核糖激酶 PRK（限速）。

C₄植物空间分离：叶肉细胞（PEP羧化酶固定CO₂→C₄酸）→维管束鞘细胞（脱羧→卡尔文循环）— 高光/高温/干旱适应。

CAM植物时间分离：夜间开气孔固定CO₂→苹果酸贮存→白天关气孔脱羧。

🎯 光呼吸（C₂循环）

条件：高O₂/低CO₂/高光/高温；RuBPCase 加氧活性→乙醇酸→过氧化物酶体/线粒体/叶绿体循环。

代价：消耗O₂/释放CO₂/耗ATP/NADPH、不产能量/不合成有机物、降低光合效率 20-50%。

工程改良：引入甘油酸途径/乙醇酸脱氢酶→旁路光呼吸→增产。

考点2.5 光合呼吸综合分析 · 大题主战场

模块二 细胞代谢

📌 速率关系铁律

总光合 = 净光合 + 呼吸；光合产O₂量 = O₂释放量 + 呼吸耗O₂量。

光合固CO₂量 = CO₂吸收量 + 呼吸产CO₂量；光合产有机物 = 积累量 + 呼吸消耗量。

📊 光补偿点 / 饱和点曲线

区段光照光合 vs 呼吸气体交换可测指标
A点（补偿点）低光合=呼吸不吸不放CO₂/O₂净光合=0
A-B段升呼吸>光合吸O₂、放CO₂净光合<0
B-C段升光合>呼吸放O₂、吸CO₂净光合>0
C点（饱和点）高光合=最大达峰受CO₂/酶/温度限制

🏆 环境因子耦合与经典题型

CO₂浓度↑：提高饱和点、提高最大速率、补偿点不变/略降。

温度↑（适宜）：酶活性↑→光合/呼吸均↑，呼吸增幅>光合→补偿点↑、饱和点↓。

水分胁迫：气孔关闭→CO₂↓→光合↓、光呼吸↑。

经典计算：同位素示踪（¹⁴CO₂标记）、遮光/突变曲线（C₃/C₅变化推断）、气体交换积分面积、呼吸商/ATP/底物联立方程。

📊 ATP / NADPH 跨膜转运规律（高频选择题）

细胞器间ATP转移NAD(P)H转移
叶绿体⇄细胞质叶绿体产ATP基本不出 / 细胞质ATP可入NADPH可出 / 细胞质NADPH可入
线粒体⇄细胞质线粒体ATP可出 / 细胞质ATP不入线粒体NADH可出（穿梭）/ 细胞质NADH可入（苹果酸-天冬氨酸穿梭）

考点3.1 细胞增殖 · 分裂图像与数量动态

模块三 细胞的生命历程

📌 有丝分裂核心特征

间期：G₁（生长/合成RNA/蛋白）→ S（DNA复制/组蛋白/着丝粒复制）→ G₂（制备纺锤体/微管蛋白）。

前期：染色质凝缩→染色体（2姐妹染色单体/1着丝粒）、核膜核仁消失、纺锤体形成。

中期：染色体排列赤道板、形态最典型/易计数、秋水仙素阻滞于此。

后期：着丝粒分裂、姐妹染色单体分离→子染色体向两极（V字形）。

末期：染色体解旋、核膜核仁重现；动物（分裂沟内陷）/植物（细胞板）。

📊 减数分裂核心差异

比较项减数Ⅰ（核心：同源分离）减数Ⅱ（类有丝：姐妹分离）
前期同源染色体联会→四分体、非姐妹染色单体交叉互换（重组）无联会、无交叉、染色体散乱
中期四分体排列赤道板两侧（自由组合）染色体排列赤道板（单列）
后期同源染色体分离（着丝粒不分裂）、染色体数减半着丝粒分裂、姐妹染色单体分离
末期形成 2 单倍体细胞（含染色单体）形成 4 单倍体配子（不含染色单体）
DNA/染色体2n/2c → n/2c（DNA不变、染色体减半）n/2c → n/1c（DNA减半、染色体数不变）

🏆 图像判断万能模板 + 数量动态

看同源/四分体：区分有丝/减数Ⅰ/减数Ⅱ。

看染色体位置：散乱=前期、单列赤道板=中期/减Ⅱ中期、双列=减Ⅰ中期。

看着丝粒分裂：分裂=有丝后期/减Ⅱ后期；不分裂=减Ⅰ后期。

看核数/形状：2核=有丝末期/减Ⅰ末期、4核=减Ⅱ末期；不均等分裂=卵母细胞。

DNA：S期翻倍（2C→4C）→有丝末期减半→减Ⅰ末期不变→减Ⅱ末期再减半。

染色体：以着丝粒计；S期不变→减Ⅰ后期减半（2n→n）→减Ⅱ不变。

染色单体：S期出现→有丝后期/减Ⅱ后期着丝粒分裂消失。

考点3.2 细胞分化与全能性

模块三 细胞的生命历程

📊 概念辨析

概念定义/本质核心判断标准高频易错点
细胞分化形态/结构/功能稳定性差异化过程实质：基因选择性表达；遗传物质不变管家基因所有细胞表达；特异基因特定表达
全能性发育成完整个体/分化成多种细胞的潜能判断标准：已发育成完整个体、或已分化出多种细胞类型精子/卵/花粉=高分化高全能；种子萌发≠全能性表现
干细胞保留分裂分化能力、自我更新胚胎干细胞（ES）：全能/多能；成体干细胞：多能/单能；iPS：诱导去分化精原干细胞→精子体现分化非全能；核移植体现核全能性

📌 分化-分裂-全能性三角关系

受精卵（全能/分裂强/未分化）→ 干细胞（多能/分裂强/低分化）→ 体细胞（无全能/分裂弱/高分化）。

例外：肝细胞/淋巴细胞/表皮基底层 — 高分化保留分裂；癌细胞 — 去分化/无限分裂。

模块三 细胞的生命历程

难点1 光呼综合曲线“隐性条件”破解

🎯 难点专讲

📌 破解模型

识别坐标含义：CO₂吸收速率=净光合；CO₂释放速率=呼吸-光合（负值）；O₂释放速率=净光合；干重增加速率=净产物积累。

补偿点/饱和点定位：曲线穿零点=光补偿点；平台期=光饱和点。

面积积分法：阴影面积=总量；早晚两个补偿点间面积=日净光合总量。

ATP产生场所判定：仅线粒体（黑暗/非绿组织/补偿点下）；线粒体+叶绿体（光照绿组织）；+细胞质基质（有氧+光合同时）。

限制因子判别：平台前=光限制；平台后=CO₂/酶/温度限制；CO₂升高平台抬高→CO₂限制。

难点2 减数分裂图像/数量“陷阱条件”

🎯 难点专讲

📊 高频坑点清单

陷阱类型典型表述正确解析
同源vs姐妹“后期染色单体分离”减Ⅰ后期分离同源（着丝粒不分）；仅减Ⅱ/有丝后期分离姐妹
染色体计数“S期染色体数加倍”以着丝粒计，S期复制未分离→染色体不变（2n）、染色单体翻倍
四分体计数“四分体数=染色体数/2”仅减Ⅰ前/中期存在，数=单倍体数 n=同源对数
自由组合时机“减Ⅱ发生自由组合”自由组合仅减Ⅰ中期（同源排列随机）；减Ⅱ无同源
基因分离时机“有丝分裂发生基因分离”等位基因分离仅减Ⅰ后期（同源分离）
交叉互换频率“交叉互换发生在减Ⅱ”仅减Ⅰ前期联会复合体（Pachynema）非姐妹间
显微照片“看形态判断有丝/减数”无法区分同源/姐妹；必须结合来源（根尖/花药）、核数、均等/不均等

🏆 多倍体 / 异常分裂进阶

三倍体（3n）：同源无法完全配对→单价体/三价体→分离混乱→配子不育。

四倍体（4n）：可形成二价体正常分离→育性恢复；但易多极纺锤体/滞后染色体。

秋水仙素：抑制微管聚合→阻滞中期→诱导多倍体/染色体标本制备。

难点3 载体构象变化与磷酸化开关

🎯 难点专讲

📌 核心机制统一认知

载体/通道蛋白：构象变化是跨膜运输/信号转导的统一物理基础。

磷酸化/去磷酸化：蛋白质功能开关的通用分子机制（激酶/磷酸酶对抗）。

ATP酶双重身份：水解ATP供能 + 磷酸化自身驱动构象变化（P型ATP酶：Na⁺/K⁺、H⁺、Ca²⁺）。

🏆 实战判题口诀

见“载体蛋白磷酸化/去磷酸化”→ 必涉及 主动运输/泵蛋白/构象变化/ATP水解。

见“通道蛋白门控/电压门控/配体门控”→ 必涉及 被动运输/易化扩散/离子流/动作电位。

见“G蛋白/第二信使/cAMP/Ca²⁺/蛋白激酶级联”→ 必涉及 信号转导/放大效应/基因表达调控。

见“核孔/NLS/Ran-GTP”→ 必涉及 核质运输/主动/选择性/双向/需能。

难点4 干细胞分类与全能性判定

🎯 难点专讲

📊 必考辨析表

细胞类型分化程度分裂能力全能性典型陷阱
受精卵/合子0（未分化）极强全能第一个全能细胞
早期胚胎（~8细胞期）低强全能单细胞可发育成完整个体
胚胎干细胞（ES）低强多能不能发育成完整个体（无滋养层）；可形成三胚层
成体干细胞中/高中多能/单能精原干细胞→精子体现分化非全能
诱导多能干细胞（iPS）逆转至低强多能（类ES）体细胞核全能性证明；自体移植低排斥
高分化体细胞极高弱/无无/核全能核移植体现核全能性
生殖细胞（精/卵/花粉）极高无/弱高（受精后）花粉培养获单倍体植株体现全能性

🏆 判定金标准

“发育成完整个体” 或 “分化成多种组织细胞类型” — 仅满足其一即表现全能性。
